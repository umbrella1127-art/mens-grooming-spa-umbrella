# リサーチ用ペルソナ（Threads・ブログ共通の参考資料）

オーナー作成。**唯一の正解ではなく、リサーチと切り口選びの参考の一つ**。ここに書かれた悩みや言葉だけに縛らず、
「普通の35〜50代男性」の日常から拾う（AGENTS.md の基本方針は変えない）。

## メイン: 高橋 健一（47歳）

- 前橋市・高崎市および周辺。既婚、子ども1〜2人。経営者・役員・士業・医師・管理職・営業責任者など、人と会うことが仕事の一部
- 必要なものには払うが、意味の分からない美容には払わない。美容への関心は中〜低
- 美容は趣味ではなく**身だしなみ・コンディション管理**。「人前で汚く見られたくない」「老けて見られたくない」「疲れて見られたくない」
- 本人は「美容の悩み」とは思っていない。「最近疲れが抜けない」「頭・首・肩が重い」「顔が疲れて見える」
  「写真を見ると老けた」「髪のボリューム」「頭皮のベタつき」「ヒゲ剃り後の肌荒れ」「眉・鼻毛・耳毛」など
- 「フェイシャルを受けたい」とは思っていない。「もう少し清潔感を出したい」「最低限整えておこう」と考える
- 競合は近隣の理容室ではなく「今まで通りで別に困っていない」という状態
- 休日の半日を潰したくない → 仕事帰り・一ヶ所で終わる・予約して待たない。**火・金は23時まで**が効く

## 高級メンズサロンへの警戒感（発信で避けること）

「意識高い人向け？」「若い人向け？」「何を頼めばいいか分からない」「高そう」「営業・化粧品を買わされそう」「通わされそう」
→ 「高級」を文章で押し出さない。高級感は写真・空間・サービスで、文章では「必要性」を説明する。

## 5本柱（切り口の分類。`research_notes.pillar` に入れる）

| pillar | 気持ち | 対応するサロンの提供内容 |
|---|---|---|
| 疲労・休息 | 疲れが取れない／頭が重い／仕事終わりに切り替えたい | ヘッドスパ・頭浸浴 |
| 清潔感・第一印象 | だらしなく見られたくない／整って見えたい（若作りではない） | カット・シェービング・鼻毛ワックス・フェイシャル |
| 老化・変化 | 髪型が決まらない／顔が疲れて見える／髪が細い／毛穴・たるみ | 育毛・ハーブピーリング・フェイシャル |
| 時間 | 休日を潰したくない／終わる時間が読めない／何ヶ所も面倒 | 火・金23時まで／カット＋シェービング＋スパを一ヶ所で |
| 抵抗感 | スキンケアが分からない／相談が恥ずかしい | 美容を頑張る場所ではなく、任せて整えて帰る場所 |

## リサーチの探し方

「メンズ美容」で探しすぎない。**彼らの日常そのもの**を探し、サロンに接続できる話題だけ拾う。
例: 「40代男性 疲れ」「経営者 睡眠」「管理職 第一印象」「40代男性 清潔感」「50代男性 老けて見える」
「経営者 身だしなみ」「男性 頭皮 悩み」「仕事帰り リフレッシュ」「40代男性 自己投資」

## 使うときの注意（AGENTS.md との整合）

- **理容室**であり美容室ではない。「美容室」と書かない（一般論でも、サロンの話でも）
- 「経営者だけ」「選ばれた人向け」のような**限定・選別表現は禁止**。ペルソナは書き手の頭の中で使い、文面では「仕事で人と会う方」程度に留める
- 「シローダーラ」等、サイトの資料（`lib/fallback-data.ts` / `supabase/seed.sql`）で確認できないメニュー名は書かない
- 統計・調査結果の数字（「○%が…」「○年の調査では…」など）は、投稿にも記事にも書かない
- 確認済みの事実: 営業時間 火・金 17:00〜23:00 ／ 土・日・祝 10:00〜19:00
