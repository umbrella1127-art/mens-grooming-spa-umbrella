# Threads のトピックタグ（1投稿に1つ）

Threads API の `topic_tag` で付ける。**本文に `#` を書かない**（タグは本文の外に付く）。
制約: 1〜50文字、`.` と `&` と `#` は使えない（DBも拒否する）。

## 選び方
1. その投稿の柱（pillar）の候補から1つ選ぶ。本文の内容と合わないタグは付けない
2. `python scripts/threads/tdb.py --context` の「タグ別の表示（T+1・T+7）」を見る
   - 表示が平均を上回っているタグは、同じ柱でもう一度使ってよい
   - まだ使っていないタグも、3本に1本は試す（同じタグを3日続けない）
3. 迷ったら、読む人が検索しそうな **普通の言葉** を選ぶ（業界用語にしない）

## 候補（柱ごと）
| 柱 | 候補 |
|---|---|
| 疲労・休息 | 仕事終わりの時間 / 40代の疲れ / 頭の疲れ / ヘッドスパ / 眠りの質 |
| 清潔感・第一印象 | 清潔感 / 身だしなみ / 40代の身だしなみ / オンライン会議 / 第一印象 |
| 老化・変化 | 40代男性 / 50代男性 / 大人の肌 / 髪のくせ / 年齢とともに |
| 抵抗感 | メンズ美容はじめて / 男の身だしなみ / 化粧水ひとつから / 美容に詳しくない |
| 時間 | 平日の夜 / 仕事帰り / 自分の時間 |
| 地域（サロンに触れる投稿だけ） | 前橋 / 前橋市 / 群馬 |
| 世界観（宣伝色の弱い投稿） | 月に一度自分を整える / 男の休息 |

候補に無いタグを使ってよいのは、上の選び方と下の禁止を満たすときだけ。使ったら報告に書く（効いたら知識整理担当がこの表に足す）。

## 使わない
- 医療的な断定: 「薄毛改善」「若返り」「治る」「効く」など
- 煽り: 「今だけ」「限定」「選ばれた男性」など
- 誤解される業態: 「メンズエステ」
- 事実と違うもの: 「個室」「完全個室」
- 載せない方針のもの: 「ホットペッパー」、電話番号
- 他の店・人の名前、流行りの無関係なタグ（表示だけを狙った便乗）
