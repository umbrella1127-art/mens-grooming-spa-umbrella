# HPB月次分析（フル実行）

引数: `$ARGUMENTS`（例 `umbrella-mens 2026-08`。省略時は設定にある店舗とinboxから自動判定）

## 実行内容

`hpb-orchestrator` サブエージェントに委譲し、パイプライン全体を回す。

```
現状確認(DB) → 集計 → [分析 ‖ コンテンツ分析] → 戦略 → レポート → 通知
```

## 手順

1. まず現状を確認する:
   ```bash
   python scripts/hpb/context.py
   ```

2. `hpb-orchestrator` を Agent ツールで起動する。プロンプトに必ず含めること:
   - 対象店舗コードと月号（引数から。無ければ inbox のファイル名から判断させる）
   - **「ホットペッパーは新規集客のための投資。評価の主軸は新規獲得数とCPA（新規獲得単価）に置く」**
   - 全工程（集計→分析→戦略→レポート→通知）を完遂すること
   - 分析担当とコンテンツ分析担当は並列で呼ぶこと
   - 戦略担当には前回提案の効果検証を必ずさせること

3. オーケストレーターの報告を受け取ったら、ユーザーへ次を伝える:
   - 今月の**新規獲得数とCPA**
   - 最大の課題と筆頭施策
   - レポートのURL（`/admin/kpi/hpb/<YYYY-MM>`）
   - Discord通知の送信状況

## 注意

- inbox にSalon Report PDFが無い場合は、ユーザーにダウンロードを促して終了する
- 途中でエラーが起きたら、`analysis_runs` テーブルに failed を記録し、どこで止まったかを報告する
- 部分的にしかデータが取れていない状態で戦略を出さない（誤った打ち手につながる）
