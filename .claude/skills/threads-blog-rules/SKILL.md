# Threads・ブログ共通ルール

## ブランドと読者

- MEN'S GROOMING SPA umbrella（群馬県前橋市・男性専用サロン）。メッセージは「月に一度、自分を整える。」
- 読者は美容に詳しくない30〜50代の普通の男性。専門用語を使わず、照れずに読める距離感で書く
- 声はサロン公式・共感型。寄り添う。説教しない。上から目線にしない
- **理容室であり、美容室ではない**。「美容室」と書かない（一般論でも同じ）
- 美容を頑張る話にしない。読者にとっては趣味ではなく**身だしなみ・コンディション管理**。
  「フェイシャルを受けたい」とは思っていない人に、「疲れて見える」「清潔感」「頭が重い」の言葉で寄り添う
- ペルソナと5本柱（疲労／清潔感／老化／時間／抵抗感）は [scripts/threads/persona.md](../../../scripts/threads/persona.md)。
  リサーチ・投稿づくりの参考の一つとして読む（唯一の正解ではない）

## 絶対ルール（AGENTS.md と同じ。違反は公開しない）

1. **医療的断定の禁止**: 治る／改善する／必ず／若返る／発毛する など。効果は「個人差があります」で受ける。
   症状が気になる読者には「気になる場合は専門医に相談を」と添える
2. **煽り禁止**: 今だけ／残り○名／急いで／大幅値引き／選ばれた男性だけ 等
3. **店舗の事実を捏造しない**: 事実の出所は `lib/fallback-data.ts` と `supabase/seed.sql`。載っていないものは書かない。
   **個室・完全個室は誤り**（正: 男性専用のスペース／男性だけの空間）。設備・実績・受賞歴も同様
4. **価格**: 確定は 月9,900円／浄12,870円／育毛1回17,600円 のみ。それ以外の金額は書かない
5. **電話番号は書かない**。CTAはLINEのみ（リンクは書かず、文章で案内する程度）。ホットペッパーは載せない
6. 「経営者だけ」「選ばれた人向け」など限定・選別表現は使わない。「高級」を文章で押し出さない。
   サイトの資料に無いメニュー名（例: シローダーラ）は書かない。統計・調査結果の数字は書かない
6b. KIRASUI「全国1%」等の実績表現は使わない
7. 他人の文章を転載しない。リサーチで拾うのは「悩みの言葉」と一般的な事実だけ

## 機械チェック

```
python scripts/threads/check_article.py --text "文面"      # Threads投稿
python scripts/threads/check_article.py path/to/file.md    # 記事
```
NGは必ず直す。「要確認」（価格らしき数字）は自分で根拠を確認する。
これは最低ライン。上の1〜7を通っているかは書き手が自分で確認する。

## データの書き込み

DBへは `python scripts/threads/tdb.py`（threads_topics / threads_trials のみ）と
`python scripts/threads/save_blog.py`（記事の下書き保存）だけを使う。posts を直接触らない。
